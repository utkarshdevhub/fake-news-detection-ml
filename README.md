# Fake News Detection Using Machine Learning

IBM–NASSCOM AI/ML Project

## Objective
Build a text-classification system that predicts whether a news article resembles the **Fake** or **Real** class learned from a labeled benchmark dataset.

> Important: this is a machine-learning classifier, not a fact-checking engine. A prediction is not proof that a story is true or false.

## Dataset
Recommended benchmark: **ISOT Fake News Dataset**, commonly distributed as `Fake.csv` and `True.csv`.
It contains article title, text, subject and date. The project uses the title + article text for classification.

Download the dataset and place:
- `data/Fake.csv`
- `data/True.csv`

## Pipeline
1. Load and label the two CSV files.
2. Combine title and body text.
3. Clean text.
4. Split into training and test sets using stratification.
5. Convert text to TF-IDF features.
6. Train Logistic Regression, Multinomial Naive Bayes and Linear SVM.
7. Compare accuracy, precision, recall and F1-score.
8. Save the best model and vectorizer.
9. Run the Streamlit application.

## Run

```bash
pip install -r requirements.txt
python train.py
streamlit run app.py
```

The training script creates:
- `models/best_model.joblib`
- `models/tfidf_vectorizer.joblib`
- `results/model_comparison.csv`
- `results/confusion_matrix.png`
- `results/model_comparison.png`

## Suggested presentation points
- Problem: misinformation spreads quickly and manual verification is difficult.
- Approach: supervised NLP classification.
- Feature engineering: TF-IDF.
- Algorithms: Logistic Regression, Naive Bayes, Linear SVM.
- Evaluation: accuracy, precision, recall, F1-score and confusion matrix.
- Limitation: dataset/domain bias and changing news styles can reduce real-world generalization.

Do not put invented accuracy numbers in the PPT. Use the values generated by `train.py`.
